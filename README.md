# DUA Inclusive Club — propuesta de diseño v1

Landing de propuesta para **DUA Inclusive Club** (Av. Juárez 2707, La Paz, Puebla). Concepto: *Welcome to our paradise*, neón rosa.

Sitio estático (HTML + CSS + JS, sin dependencias). Ver en local: `python3 -m http.server 3032`.

Los eventos están en el objeto `DUA.eventos` del script: se agrega el flyer y la fecha, y la página sola decide cuál es el próximo show y cuáles "se vivieron".

> Horario y textos del espacio seguro por confirmar con DUA.
